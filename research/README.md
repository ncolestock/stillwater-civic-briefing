# Research briefings

The research automation writes one file here per event: `YYYY-MM-DD-slug.md`.

These files are not the paper. The site does not build them. The writer automation turns a briefing into a draft in `src/content/articles/`. The fact-check automation is the only step that sets that draft to `published`.

A briefing that has already been written keeps `status: filed` so the next morning does not research it again.
